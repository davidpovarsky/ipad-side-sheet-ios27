# iPadOS 27 Native Side Sheet Lab

An actual SwiftUI `.sheet` using `.presentationPlacement(.trailing)` and three native detents. Built and screenshot-tested on iPadOS 27 simulators by GitHub Actions. Screenshots are uploaded as workflow artifacts.

**Evidence rules:** Full-size iPad, portrait iPad, and iPhone screenshots are labeled separately. iPhone is not proof that an iPad window was resized. No custom overlay or Inspector stands in for a native sheet.

Open **Actions** and download the `native-sheet-screenshots` artifact from the latest run. See `ci/README.md` for test scope and limitations.
